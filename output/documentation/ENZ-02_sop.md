# Standard Operating Procedure: Recombinant Industrial Lipase - E. coli Fermentation Process

**SOP Number:** SOP-ENZ-02-001  
**Process ID:** ENZ-02  
**Revision:** 1.0  
**Effective Date:** 2026-09-30  
**Supersedes:** None (new procedure for technology transfer)

## 1. Purpose and Scope

This SOP defines the step-by-step operating procedure for manufacturing Recombinant Industrial Lipase - E. coli Fermentation Process (Recombinant enzyme (microbial, intracellular inclusion-body-free)) at the receiving commercial manufacturing site, 3000 L production fermenter. It applies to all manufacturing personnel executing this process and to QA personnel reviewing associated batch records.

## 2. Responsibilities

- **Manufacturing Operators:** Execute each unit operation per the parameters specified below and record all data contemporaneously in the batch record.
- **Manufacturing Supervisor:** Verify equipment readiness and line clearance before each unit operation; review in-process data.
- **Quality Assurance:** Review the executed batch record against this SOP and the process description document; approve final disposition.
- **Quality Control:** Perform release testing per Section 4 and report results against the approved specifications.

## 3. Materials and Equipment

| Step | Equipment |
|---|---|
| 1. Seed Fermentation | Shake flasks, 10 L stirred-tank fermenter |
| 2. Production Fermentation (Fed-Batch, IPTG Induction) | 150 L stainless steel fermenter |
| 3. Cell Harvest (Centrifugation) | Disc-stack centrifuge |
| 4. High-Pressure Homogenization (Lysis) | High-pressure homogenizer |
| 5. Clarification (Depth Filtration) | Depth filter train |
| 6. Anion Exchange Capture | Q Sepharose column |
| 7. Hydrophobic Interaction Chromatography Polish | Phenyl Sepharose column |

## 4. Procedure

### 4.1 Seed Fermentation

1. Confirm equipment (Shake flasks, 10 L stirred-tank fermenter) is qualified and within calibration.
2. Shake flask to 10 L seed fermenter expansion, 16-18 hr, OD600 target reached before transfer.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| duration_hr | 16-18 |
| od600_target | 8-12 |
| temperature_c | 37.0 +/- 0.5 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.2 Production Fermentation (Fed-Batch, IPTG Induction)

1. Confirm equipment (150 L stainless steel fermenter) is qualified and within calibration.
2. 150 L fed-batch fermentation with glycerol feed; IPTG induction at mid-log phase for recombinant expression.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| induction_od600 | 40-60 |
| iptg_concentration_mm | 0.5 +/- 0.1 |
| post_induction_duration_hr | 18-20 |
| temperature_c_post_induction | 25.0 +/- 0.5 |
| do_pct | 30 +/- 10 |
| ph_setpoint | 6.80 +/- 0.10 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.3 Cell Harvest (Centrifugation)

1. Confirm equipment (Disc-stack centrifuge) is qualified and within calibration.
2. Continuous centrifugation to pellet cells; resuspend in lysis buffer.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| bowl_speed_rpm | 8000-10000 |
| feed_flow_lpm | 5-10 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.4 High-Pressure Homogenization (Lysis)

1. Confirm equipment (High-pressure homogenizer) is qualified and within calibration.
2. Two passes through high-pressure homogenizer to lyse cells and release soluble enzyme.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| pressure_bar | 800-1000 |
| passes | 2 |
| post_lysis_temperature_c | <=15 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.5 Clarification (Depth Filtration)

1. Confirm equipment (Depth filter train) is qualified and within calibration.
2. Depth filtration to remove cell debris from lysate.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| flux_lmh | 40-120 |
| max_turbidity_ntu_post | <=15 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.6 Anion Exchange Capture

1. Confirm equipment (Q Sepharose column) is qualified and within calibration.
2. IEX bind-elute capture step exploiting target enzyme's acidic pI.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_g_per_l_resin | <=25 |
| gradient_nacl_mm | 50-400 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.7 Hydrophobic Interaction Chromatography Polish

1. Confirm equipment (Phenyl Sepharose column) is qualified and within calibration.
2. HIC step to remove host cell protein and aggregated species.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_ammonium_sulfate_m | 1.0-1.2 |
| load_g_per_l_resin | <=20 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.8 UF/DF Formulation

1. Confirm equipment (Tangential flow filtration, 10 kDa MWCO) is qualified and within calibration.
2. Ultrafiltration/diafiltration into final storage buffer with stabilizing excipients.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| target_concentration_mg_ml | 20 +/- 2 |
| diavolumes | >=6 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.9 Sterile Filtration & Fill

1. Confirm equipment (0.2 um PES sterile filter) is qualified and within calibration.
2. 0.2 um sterile filtration into final bulk containers.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| bioburden_cfu_per_100ml | <=1 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

## 5. In-Process Controls and Release Testing

Samples are pulled per the in-process control plan referenced in the process description document. Final drug substance/intermediate is released against the following specifications:

| Attribute | Specification | Unit |
|---|---|---|
| specific_activity_u_per_mg | >=800 | U/mg |
| purity_sds_page_pct | >=95.0 | % |
| hcp_ppm | <=100 | ppm |
| residual_dna_pg_per_mg | <=10 | pg/mg |
| endotoxin_eu_per_mg | <=5.0 | EU/mg |
| bioburden_cfu_per_10ml | <=1 | CFU/10mL |
| ph_final | 7.0-7.4 | pH |
| moisture_content_pct | <=5.0 | % |

## 6. Deviation Handling

Any excursion outside the CPP ranges or release specifications in this SOP is handled per the site's deviation management SOP. QA must assess impact to product quality before batch disposition.
