# Standard Operating Procedure: Anti-TNF IgG1 Monoclonal Antibody - CHO Fed-Batch Process

**SOP Number:** SOP-mAb-01-001  
**Process ID:** mAb-01  
**Revision:** 1.0  
**Effective Date:** 2026-09-30  
**Supersedes:** None (new procedure for technology transfer)

## 1. Purpose and Scope

This SOP defines the step-by-step operating procedure for manufacturing Anti-TNF IgG1 Monoclonal Antibody - CHO Fed-Batch Process (Monoclonal antibody (IgG1)) at the receiving commercial manufacturing site, 2000 L production bioreactor. It applies to all manufacturing personnel executing this process and to QA personnel reviewing associated batch records.

## 2. Responsibilities

- **Manufacturing Operators:** Execute each unit operation per the parameters specified below and record all data contemporaneously in the batch record.
- **Manufacturing Supervisor:** Verify equipment readiness and line clearance before each unit operation; review in-process data.
- **Quality Assurance:** Review the executed batch record against this SOP and the process description document; approve final disposition.
- **Quality Control:** Perform release testing per Section 4 and report results against the approved specifications.

## 4. Procedure

### 4.1 Cell Thaw & Seed Train Expansion

1. Confirm equipment (Shake flasks, 5 L single-use bioreactor) is qualified and within calibration.
2. Thaw WCB vial, expand through shake flasks and seed bioreactors (N-2, N-1) over 10-12 days to reach inoculation density.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| culture_duration_days | 10-12 |
| seed_viability_pct | >=95 |
| inoculation_vcd_e6_per_ml | 0.3-0.5 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.2 Production Bioreactor (Fed-Batch)

1. Confirm equipment (200 L stainless steel bioreactor) is qualified and within calibration.
2. 200 L fed-batch culture with daily glucose-controlled feed, 14-day run, temperature shift on day 7 to extend productivity.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| temperature_c_phase1 | 37.0 +/- 0.5 |
| temperature_c_phase2 | 33.0 +/- 0.5 |
| ph_setpoint | 7.00 +/- 0.10 |
| do_pct | 40 +/- 10 |
| culture_duration_days | 14 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.3 Harvest Clarification

1. Confirm equipment (Depth filter train + 0.2 um PES filter) is qualified and within calibration.
2. Depth filtration followed by 0.2 um sterile filtration to remove cells and debris.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| flux_lmh | 50-150 |
| max_turbidity_ntu_post | <=20 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.4 Protein A Capture Chromatography

1. Confirm equipment (Protein A column, 20 cm bed height) is qualified and within calibration.
2. MabSelect SuRe resin, bind-elute mode, low pH elution.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_g_per_l_resin | <=35 |
| elution_ph | 3.5 +/- 0.2 |
| residence_time_min | 4-6 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.5 Low pH Viral Inactivation

1. Confirm equipment (per Process Description) is qualified and within calibration.
2. Hold Protein A eluate at low pH for 60 min to inactivate enveloped viruses, then neutralize.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| hold_ph | 3.6 +/- 0.1 |
| hold_time_min | >=60 |
| hold_temperature_c | 18-25 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.6 Anion Exchange Polish (Flow-Through)

1. Confirm equipment (Q membrane adsorber) is qualified and within calibration.
2. AEX membrane/resin flow-through mode to remove HCP, DNA, and aggregates.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_g_per_l_resin | <=100 |
| conductivity_ms_cm | <=8 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.7 Cation Exchange Polish (Bind-Elute)

1. Confirm equipment (CEX resin column) is qualified and within calibration.
2. CEX bind-elute step to further remove HCP, leached Protein A, and charge variants.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_g_per_l_resin | <=40 |
| gradient_nacl_mm | 0-300 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.8 Viral Filtration

1. Confirm equipment (Virosart / Planova-type filter) is qualified and within calibration.
2. Nanofiltration (20 nm pore) for robust parvovirus clearance.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| max_flux_lmh | <=10 |
| max_pressure_bar | <=2.8 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.9 UF/DF Formulation

1. Confirm equipment (Tangential flow filtration, 30 kDa MWCO) is qualified and within calibration.
2. Ultrafiltration/diafiltration to target concentration and final formulation buffer.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| target_concentration_mg_ml | 50 +/- 5 |
| diavolumes | >=8 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.10 Sterile Filtration & Fill

1. Confirm equipment (0.2 um PVDF sterile filter) is qualified and within calibration.
2. 0.2 um sterile filtration into final bulk containers.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| bioburden_cfu_per_100ml | <=1 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

## 5. In-Process Controls and Release Testing

Samples are pulled per the in-process control plan referenced in the process description document. Final drug substance/intermediate is released against the following specifications:

| Attribute | Specification | Unit |
|---|---|---|
| titer_g_per_l | >=3.0 | g/L |
| purity_sec_pct_monomer | >=98.0 | % |
| hcp_ppm | <=50 | ppm |
| protein_a_ppm | <=5 | ppm |
| endotoxin_eu_per_mg | <=0.5 | EU/mg |
| bioburden_cfu_per_10ml | <=1 | CFU/10mL |
| ph_final | 6.0-6.4 | pH |
| osmolality_mosm_kg | 270-330 | mOsm/kg |

## 6. Deviation Handling

Any excursion outside the CPP ranges or release specifications in this SOP is handled per the site's deviation management SOP. QA must assess impact to product quality before batch disposition.
