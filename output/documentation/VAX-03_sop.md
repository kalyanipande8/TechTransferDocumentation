# Standard Operating Procedure: Plasmid DNA Drug Substance - E. coli Fermentation & AEX Downstream Process

**SOP Number:** SOP-VAX-03-001  
**Process ID:** VAX-03  
**Revision:** 1.0  
**Effective Date:** 2026-09-30  
**Supersedes:** None (new procedure for technology transfer)

## 1. Purpose and Scope

This SOP defines the step-by-step operating procedure for manufacturing Plasmid DNA Drug Substance - E. coli Fermentation & AEX Downstream Process (Plasmid DNA (pDNA) for gene therapy / vaccine applications) at the receiving commercial manufacturing site, 1500 L production fermenter. It applies to all manufacturing personnel executing this process and to QA personnel reviewing associated batch records.

## 2. Responsibilities

- **Manufacturing Operators:** Execute each unit operation per the parameters specified below and record all data contemporaneously in the batch record.
- **Manufacturing Supervisor:** Verify equipment readiness and line clearance before each unit operation; review in-process data.
- **Quality Assurance:** Review the executed batch record against this SOP and the process description document; approve final disposition.
- **Quality Control:** Perform release testing per Section 4 and report results against the approved specifications.

## 3. Materials and Equipment

| Step | Equipment |
|---|---|
| 1. Seed Train Expansion | Shake flasks, 5 L stirred-tank fermenter |
| 2. Production Fermentation (Fed-Batch) | 100 L stainless steel fermenter |

| 4. Alkaline Lysis & Neutralization | In-line static mixer, hold tanks |
| 5. Clarification (Depth Filtration) | Depth filter train |

| 10. Sterile Filtration & Fill | 0.2 um PES sterile filter |

## 4. Procedure

### 4.1 Seed Train Expansion

1. Confirm equipment (Shake flasks, 5 L stirred-tank fermenter) is qualified and within calibration.
2. Glycerol stock to shake flask to 5 L seed fermenter, antibiotic-free selective medium.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| duration_hr | 12-14 |
| od600_target | 4-6 |
| temperature_c | 37.0 +/- 0.5 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.2 Production Fermentation (Fed-Batch)

1. Confirm equipment (100 L stainless steel fermenter) is qualified and within calibration.
2. 100 L fed-batch fermentation to high cell density, non-antibiotic plasmid maintenance system.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| harvest_od600 | 80-100 |
| duration_hr | 16-18 |
| temperature_c | 37.0 +/- 0.5 |
| ph_setpoint | 7.00 +/- 0.10 |
| do_pct | 30 +/- 10 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.3 Cell Harvest (Centrifugation)

1. Confirm equipment (Disc-stack centrifuge) is qualified and within calibration.
2. Continuous centrifugation to pellet cells for alkaline lysis.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| bowl_speed_rpm | 8000-10000 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.4 Alkaline Lysis & Neutralization

1. Confirm equipment (In-line static mixer, hold tanks) is qualified and within calibration.
2. NaOH/SDS lysis followed by potassium acetate neutralization to precipitate genomic DNA and protein.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| lysis_time_min | 5 +/- 1 |
| neutralization_hold_time_min | 15-20 |
| lysate_temperature_c | 15-20 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.5 Clarification (Depth Filtration)

1. Confirm equipment (Depth filter train) is qualified and within calibration.
2. Depth filtration to remove precipitated gDNA/protein/cell debris flocs.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| flux_lmh | 30-80 |
| max_turbidity_ntu_post | <=10 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.6 Endotoxin/RNA Reduction (Selective Precipitation)

1. Confirm equipment (Agitated precipitation vessel) is qualified and within calibration.
2. Calcium chloride precipitation step to reduce residual RNA and endotoxin ahead of chromatography.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| cacl2_concentration_m | 0.3-0.5 |
| hold_time_min | 30-60 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.7 Anion Exchange Capture Chromatography

1. Confirm equipment (Q resin column) is qualified and within calibration.
2. AEX bind-elute step, resolving supercoiled plasmid from open-circular/linear isoforms and RNA.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_mg_per_ml_resin | <=5 |
| gradient_nacl_m | 0.8-1.2 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.8 Size-Exclusion / Hydrophobic Polish

1. Confirm equipment (SEC or HIC column) is qualified and within calibration.
2. Polish step to further enrich supercoiled topology and remove residual HCP/endotoxin.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| load_mg_per_ml_resin | <=3 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.9 Tangential Flow Filtration (Concentration/Diafiltration)

1. Confirm equipment (Tangential flow filtration, 100-300 kDa MWCO) is qualified and within calibration.
2. TFF to concentrate and exchange into final formulation buffer (TE or saline).
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| target_concentration_mg_ml | 2.0 +/- 0.2 |
| diavolumes | >=10 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

### 4.10 Sterile Filtration & Fill

1. Confirm equipment (0.2 um PES sterile filter) is qualified and within calibration.
2. 0.2 um sterile filtration into final bulk containers.
3. Operate within the following critical process parameters, recording actual values in the batch record at the frequency specified in the in-process control plan:

| Parameter | Target / Limit |
|---|---|
| bioburden_cfu_per_100ml | <=1 |

4. If any parameter deviates from the stated range, initiate a deviation report per site deviation-management procedure before proceeding.

## 5. In-Process Controls and Release Testing

Samples are pulled per the in-process control plan referenced in the process description document. Final drug substance/intermediate is released against the following specifications:

| Attribute | Specification | Unit |
|---|---|---|
| pct_supercoiled | >=85.0 | % |
| concentration_mg_ml | 1.8-2.2 | mg/mL |
| residual_gdna_pct | <=1.0 | % |
| residual_rna_pct | <=1.0 | % |
| residual_protein_ug_mg | <=2.0 | ug/mg |
| endotoxin_eu_per_mg | <=10.0 | EU/mg |
| bioburden_cfu_per_10ml | <=1 | CFU/10mL |
| identity_restriction_digest | conforms | pass/fail |
| residual_antibiotic_ppm | <=0.1 | ppm |

## 6. Deviation Handling

Any excursion outside the CPP ranges or release specifications in this SOP is handled per the site's deviation management SOP. QA must assess impact to product quality before batch disposition.
